# 图片风格规范

> 根据年龄段自动选择最合适的视觉风格

---

## 📋 风格定义

### 幼儿园（3-6岁）

| 属性 | 配置 |
|------|------|
| **风格** | 儿童插画 |
| **特点** | 线条圆润、色彩鲜艳、形象卡通、背景简洁 |
| **色彩** | 高饱和度、暖色调为主 |
| **比例** | 4:3 或 1:1 |
| **分辨率** | 512x512 或 768x768 |
| **适用** | 所有示例图、插图 |

**提示词模板**：
```
儿童插画风格，线条圆润可爱，色彩鲜艳明亮，扁平化设计，简洁背景，
适合幼儿认知，教育类插图，{主题内容}
```

**示例**：
- 数字1-10的卡通形象
- 苹果、小鸟、花朵等生活化例子
- 简单的几何图形认知

---

### 小学低年级（1-2年级）

| 属性 | 配置 |
|------|------|
| **风格** | 彩色手绘 |
| **特点** | 有笔触感、温馨亲切、略带童趣但不幼稚 |
| **色彩** | 柔和色调、明亮但不刺眼 |
| **比例** | 16:9 或 4:3 |
| **分辨率** | 768x768 或 1024x768 |
| **适用** | 概念图、示例图 |

**提示词模板**：
```
手绘插画风格，柔和色彩，温馨亲切，适合小学生，教育类插图，
有笔触感但不凌乱，{主题内容}
```

---

### 小学高年级（3-6年级）

| 属性 | 配置 |
|------|------|
| **风格** | 扁平设计 |
| **特点** | 简洁现代、信息清晰、专业但不枯燥 |
| **色彩** | 蓝绿色系为主、中性色调 |
| **比例** | 16:9 |
| **分辨率** | 1024x576 或 1280x720 |
| **适用** | 概念图、公式图解、示意图 |

**提示词模板**：
```
扁平化设计风格，简洁现代，信息清晰，适合小学生，教育类插图，
蓝绿色调为主，专业但不失趣味，{主题内容}
```

---

### 初中（7-9年级）

| 属性 | 配置 |
|------|------|
| **风格** | 科学插图 |
| **特点** | 准确清晰、专业感、逻辑性强 |
| **色彩** | 冷色调为主、低饱和度 |
| **比例** | 16:9 |
| **分辨率** | 1920x1080 |
| **适用** | 公式图解、实验示意图、概念图 |

**提示词模板**：
```
科学插图风格，准确清晰，专业感强，适合初中生，教育类图表，
冷色调为主，逻辑清晰，{主题内容}
```

```python
        'resolution': '768x576'
    },
    'grade3-6': {
        'style': 'flat_design',
        'prompt_template': '扁平化设计风格，简洁现代，信息清晰，适合小学生，教育类插图，蓝绿色调为主，专业但不失趣味，{topic}',
        'aspect_ratio': '16:9',
        'resolution': '1024x576'
    },
    'middle_school': {
        'style': 'scientific_illustration',
        'prompt_template': '科学插图风格，准确清晰，专业感强，适合初中生，教育类图表，冷色调为主，逻辑清晰，{topic}',
        'aspect_ratio': '16:9',
        'resolution': '1920x1080'
    }
}

def get_style_config(age_group):
    """根据年龄段获取风格配置"""
    if age_group == 'kindergarten':
        return STYLE_CONFIG['kindergarten']
    elif age_group in ['grade1', 'grade2']:
        return STYLE_CONFIG['grade1-2']
    elif age_group in ['grade3', 'grade4', 'grade5', 'grade6']:
        return STYLE_CONFIG['grade3-6']
    else:  # grade7-9
        return STYLE_CONFIG['middle_school']
```

## ✅ 验收标准

每张生成的图片需要检查：
- [ ] 风格是否符合年龄段
- [ ] 色彩是否合适（幼儿园鲜艳，初中冷静）
- [ ] 内容是否清晰易懂
- [ ] 是否有不必要的细节
- [ ] 是否符合教育类插图标准
