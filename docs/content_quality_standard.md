# 高质量内容生成规范

## 质量标准

### 1. 讲解内容（explanation）
- **字数要求**：200-400字
- **必须包含**：
  - 通俗解释（用生活例子说明概念）
  - 核心公式/定理（清晰呈现）
  - 至少2个具体例子
  - 常见误区提醒
  - 记忆技巧（如有）
- **禁止**：只堆砌定义、空洞说教、照搬百科

### 2. 练习题（quiz）
- **数量**：3-5道选择题
- **每道题必须包含**：
  - 题目（情景化，不空洞）
  - 四个选项A/B/C/D
  - 正确答案
  - 详细解析（为什么对、为什么错）
- **难度分布**：基础题60% + 提高题30% + 易错题10%

### 3. 图片（image）
- 与知识点主题相关
- 简洁明了，适合学习场景
- 分辨率1024x768

### 4. 音频（audio）
- 全文朗读（讲解+题目）
- 时长控制在2-3分钟
- 使用适合年龄段的音色

## 各年级具体要求

### 幼儿园(3-6岁)
- 讲解：故事化、游戏化语言
- 题目：看图选择、简单判断
- 图片：卡通风格、色彩鲜艳
- 音频：温柔女声（XiaoyiNeural）

### 小学1-3年级
- 讲解：口语化、多举生活例子
- 题目：基础计算、概念辨析
- 图片：实物图、示意图
- 音频：标准女声（XiaoxiaoNeural）

### 小学4-6年级
- 讲解：逻辑清晰、有解题技巧
- 题目：应用题、思维拓展题
- 图片：流程图、思维导图
- 音频：标准女声

### 初中7-9年级
- 讲解：考点明确、有应试技巧
- 题目：中考真题风格、易错题
- 图片：公式图、解题步骤图
- 音频：男声（YunxiNeural）

## 执行规范

1. **RPM控制**：每请求间隔4.5秒，严格≤20 RPM
2. **分批执行**：每批20个知识点，完成后暂停检查
3. **质量检查**：生成后随机抽查3个验证质量
4. **错误重试**：API失败自动重试，最多3次
